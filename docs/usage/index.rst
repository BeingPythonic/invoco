Usage
=====

Getting started with Invoco.

.. toctree::

Installation
------------

To install for development:

.. code-block:: bash

   git clone git@github.com:beingpythonic/invoco.git
   cd invoco
   hatch env create

Examples
--------

Echo Task:

.. code-block:: bash

   invoco examples/echo.json
